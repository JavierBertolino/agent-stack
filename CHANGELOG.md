# Changelog

All notable user-facing changes are documented here.

## 0.1.0

First public release candidate.

- `astack` is the canonical CLI.
- One-command installation from tagged GitHub Releases.
- `astack update` updates the global CLI/kit.
- `astack upgrade` safely migrates project-managed sources.
- OpenSpec-backed local or mirrored specs workflow.
- Multi-select platform and integration setup.
- Jev QA configuration during init or through `astack auth jev`.
- TypeSafe direct, Vercel AI Gateway, and custom gateway configuration routes.
- Project-agnostic Jev QA business-rule questions.
