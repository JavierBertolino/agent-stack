# agent-stack

Node.js front door for Agent Stack. `npx agent-stack init` parses flags, asks for coding agents and integrations, then runs the shell renderer that writes project files.

Requires Node.js 18 or newer.

```sh
npx agent-stack init
npm install -g agent-stack
```

The curl installer still installs the `astack` command. See `docs/node-cli.md` in the kit repository for what remains in the shell.
